## 📁 Dataset Setup

Download the dataset from [Google Drive](https://drive.google.com/drive/folders/13IFa81czS4xTMwJ4vo1JeihSGcN3zRUp?usp=share_link).

Extract the files so your folder structure looks like this:

```text
cephalometric-analysis/
├── phase1_landmarks/
│   └── data/
│       ├── RawImage/
│       └── AnnotationsByMD/
└── phase2_cvm/
    └── Aariz/
        ├── train/
        ├── valid/
        └── test/
```
